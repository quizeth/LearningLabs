# Credenciales de Microsoft Applied Skills

## ¿Qué son las Applied Skills?

Las Applied Skills son credenciales oficiales de Microsoft que validan una aptitud concreta y te permiten mostrarla en tu perfil de Microsoft Learn.

- **Evaluación:** práctica, en un laboratorio interactivo con tareas similares a las del trabajo real.
- **Preparación:** consulta la guía de estudio oficial y practica las tareas relacionadas.
- **Duración:** depende de la credencial; revisa su página para conocer el tiempo disponible.
- **Reintento:** si inicias una evaluación, espera 72 horas antes de iniciar otro intento.
- **Al aprobar:** podrás ver y compartir tu credencial digital desde Microsoft Learn.
