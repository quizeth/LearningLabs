# Laboratorio 1: Primeros pasos con Microsoft 365 Copilot Chat

Imagina que eres un/a asociado/a de operaciones de negocio en una consultora de tamaño medio. Tu responsable te ha pedido que lideres la planificación de una próxima Cumbre de Innovación para Clientes. Utilizarás Microsoft 365 Copilot para recopilar información, generar ideas, visualizar la agenda, redactar un documento de planificación, resumirlo y colaborar con tus compañeros/as.

### Objetivos de aprendizaje 
En este ejercicio aprenderás a:

- Navegar y crear prompts en Microsoft 365 Copilot Chat.

- Usar Copilot para investigar tendencias, generar ideas y crear contenido visual.

- Redactar documentos de planificación y convertirlos en archivos de Word.

- Analizar archivos subidos y generar comunicaciones a partir de ellos.

- Colaborar en tiempo real usando Copilot Pages.

**Duración estimada:** 20 minutos

!!! note "Nota"

  > Para completar este laboratorio necesitas acceso a Microsoft 365 Copilot. Si tienes **Work IQ** habilitado, algunas respuestas pueden incorporar datos de tu organización y diferir de los resultados esperados. Para los ejercicios de investigación, prioriza las fuentes web.
  

---

### Tarea 1: Resumir tendencias del sector para la planificación del evento

Copilot Chat puede ayudarte a identificar rápidamente las principales tendencias de innovación en la web que sean relevantes para tu cumbre. Esta es la base para diseñar la agenda del evento en torno a temas significativos que conecten con tu audiencia de clientes.

- **Abre Microsoft Copilot** (m365.cloud.microsoft o la app de escritorio de Microsoft 365 Copilot).

- **Copia y envía** el siguiente prompt:
```
¿Cuáles son las tres principales tendencias de innovación en [tu sector] para 2025 y cómo pueden dar forma a la agenda de una cumbre de clientes?
```
  > ℹ️ **NOTA:** Sustituye [sector] por el sector que prefieras.

- Selecciona **Enviar (icono de flecha)** en la parte inferior derecha del cuadro de texto o pulsa **Enter** en tu teclado.

- Revisa la información proporcionada por Copilot y, si es necesario, refina el prompt.

### Tarea 2: Lluvia de ideas y borrador de sesiones

A partir de las tendencias que acabas de investigar, usa Copilot para generar títulos y descripciones de sesiones atractivas y relevantes. Esto te ayuda a transformar información en bruto en elementos concretos de agenda que aporten valor a los asistentes al evento.


- En el mismo chat con Copilot, **copia y envía** este prompt:

```
Basándote en esas tendencias, sugiere 5 títulos de sesiones atractivos y escribe descripciones breves para una cumbre de innovación de clientes.
```

- Selecciona **Enviar**, revisa la información proporcionada por Copilot y, si es necesario, refina el prompt.
  
- **Envía este prompt de seguimiento:**
  
```
Haz que las descripciones sean más atractivas usando un tono dinámico y profesional.
```

- Selecciona **Enviar**, revisa la información proporcionada por Copilot y, si es necesario, refina el prompt.

### Tarea 3: Visualizar la línea de tiempo de la agenda y crear un logotipo

Copilot Chat puede ayudarte a convertir rápidamente ideas en texto en contenido visual. En esta tarea, generarás una línea de tiempo para la cumbre y un logotipo que refleje la temática del evento, útiles para materiales promocionales y relacionados con la cumbre.

- En el mismo chat con Copilot, **copia y envía** este prompt:
```
Crea una línea de tiempo de la agenda para una cumbre de un día centrada en [tendencia] con una introducción, cierre, sesiones a las 9:00, 11:00, 13:30 y 15:00, dos mini descansos y una hora de pausa para comer, en formato de tabla.
```
  > ℹ️ **NOTA:** Sustituye [tendencia] por una de las tendencias listadas en la Tarea 1.

- Selecciona **Enviar**, revisa la información proporcionada por Copilot y, si es necesario, refina el prompt.
  
- Envía este prompt de seguimiento:

```
Crea un logotipo sencillo y moderno para esta cumbre de innovación de clientes.
```

- Selecciona **Enviar**, revisa la imagen proporcionada por Copilot y, si es necesario, refina el prompt.

### Tarea 4: Redactar un documento de planificación para la cumbre
Ahora que has definido la estructura y las ideas para tu evento, usa Copilot Chat para crear un resumen de planificación que puedas convertir en un documento de Word. Este documento servirá como referencia central del proyecto, recogiendo objetivos, detalles de las sesiones y métricas de éxito en un solo lugar.

- En el mismo chat con Copilot, **copia y envía** este prompt:

```
Crea un resumen de planificación de una página para esta cumbre de innovación de clientes que incluya: objetivos, audiencia, temas de las sesiones e hitos clave de planificación.
```

- Selecciona **Enviar**, revisa la información proporcionada por Copilot y, si es necesario, refina el prompt.
  
- Envía este prompt de seguimiento:

```
Añade una sección que resuma los resultados esperados y las métricas de éxito del evento.
```

- Selecciona **Enviar**, revisa la información proporcionada por Copilot y, si es necesario, refina el prompt.
  
- Envía este prompt para crear el documento de Word:

```
Crea un documento de Word con este resumen de planificación.
```

- Abre el documento de **Word** generado.
  
- Si se te pide iniciar sesión, introduce tu correo electrónico corporativo y selecciona **Siguiente**.

- En la pantalla de **Introducir contraseña**, escribe tu contraseña y selecciona **Iniciar sesión**.

- Si se te pregunta **¿Mantener la sesión iniciada?**, marca la casilla **No volver a mostrar** y selecciona **Sí**.
  
- Selecciona **Archivo** > **Guardar como** > **Este equipo** e introduce un nombre de archivo (ej.: *Resumen de Planificación de la Cumbre de Clientes*).
  
- Selecciona **Guardar** y luego **cierra** el documento.
  
- Regresa a tu conversación de Copilot Chat para completar la Tarea 5.

### Tarea 5: Analizar y generar contenido a partir de un archivo

En esta tarea, subirás el resumen de planificación de la Tarea 4 y harás que Copilot lo resuma y genere una comunicación interna. Esto demuestra cómo Copilot puede ahorrarte tiempo al convertir documentos en contenido resumido y listo para actuar.

- Continúa en Copilot Chat. **Copia y envía** este prompt y sube el archivo que creaste en la Tarea 4:

```
Resume los puntos clave de este resumen de planificación en solo 5 viñetas condensadas:
```

- Selecciona el **icono de +** > **Cargar** > **Cargar imágenes y archivos** en la esquina inferior derecha del cuadro de texto para abrir el Explorador de archivos.
  
- Selecciona **Documentos** a la derecha del Explorador de archivos para localizar tu documento guardado en la **Tarea 4**.
  
- Selecciona tu documento y luego selecciona **Abrir** para subir el archivo al cuadro de texto de Copilot Chat.
  
- Una vez que veas que el archivo se ha subido al cuadro de texto, selecciona **Enviar**.
  
- Revisa la información proporcionada por Copilot y, si es necesario, refina el prompt.
  
- Envía este prompt de seguimiento:

```
Redacta un correo electrónico de seguimiento al equipo de planificación con estos puntos destacados y los próximos pasos.
```

- Selecciona **Enviar**, revisa la información proporcionada por Copilot y, si es necesario, refina el prompt.

### Tarea 6: Colaborar usando Copilot Pages

Convierte el borrador de correo de la Tarea 5 en un espacio de trabajo colaborativo usando Copilot Pages. Esto te permitirá simular cómo varios miembros del equipo pueden refinar contenido en tiempo real.

- Selecciona **Editar en Pages** debajo de la última respuesta de Copilot en la **Tarea 5** (o cualquier respuesta que prefieras) para copiar esa información a Copilot Pages.
  
- Se abrirá una nueva página de Copilot en el panel derecho de Copilot Chat. Explora las siguientes acciones:
  - Dale un nuevo título a la página en la parte superior.
    
  - Escribe contenido adicional en cualquier parte de la página haciendo clic en ella.
    
  - Añade una respuesta adicional de Copilot Chat (anterior o nueva) a la página seleccionando **Agregar a la página** en la parte inferior de la respuesta.
    
  - Escribe **"/"** para insertar bloques de contenido, como una tabla o una lista de verificación.
    
  - **@menciona** a un/a compañero/a (o simúlalo) y concédele acceso seleccionando **Compartir y notificar** en el mensaje emergente que aparece al agregar su nombre.
    
  - Opcionalmente, comparte tu página seleccionando el icono de **Compartir** en la parte superior derecha de la página y eligiendo una de las dos opciones para copiar un enlace.

### Tarea opcional de cierre: Revisión y reflexión

- En el mismo chat con Copilot, **copia y envía** este prompt:

```
Crea una lista de verificación de lo que aprendí hoy usando Copilot Chat y cómo puedo aplicarlo a mi [rol].
```

  > ℹ️ **NOTA:** Sustituye [rol] por tu puesto de trabajo.

### Resumen

| Concepto | Punto clave |
|---|---|
| **Investigación con Copilot** | Usa prompts para identificar tendencias del sector y fundamentar la agenda de un evento. |
| **Generación de ideas** | Copilot puede crear títulos, descripciones y contenido visual (logotipos, líneas de tiempo). |
| **Creación de documentos** | Transforma respuestas de Copilot en documentos de Word listos para compartir. |
| **Análisis de archivos** | Sube documentos a Copilot para obtener resúmenes y generar comunicaciones derivadas. |
| **Colaboración con Pages** | Copilot Pages permite editar y compartir contenido en tiempo real con tu equipo. |
